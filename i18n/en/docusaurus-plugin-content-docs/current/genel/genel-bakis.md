**Cloud2Biz** is a secure, highly available **cloud service provider** operating since 2004. It delivers virtual servers, object storage, managed Kubernetes and a container-based application platform from its own data center infrastructure.

## Services

| Service | Description | Documentation |
| --- | --- | --- |
| **FlexoStack Cloud** | A flexible cloud platform where you adjust CPU, RAM and disk resources as needed: virtual servers, networking, storage, backups and managed Kubernetes | [FlexoStack Cloud](/docs/flexostack-cloud) |
| **Object Storage** | Amazon S3-compatible object storage | [Object Storage](/docs/object-storage) |
| **BizPaaS** | A container-based platform as a service (PaaS) to deploy and scale applications; for development teams and microservice architectures | [cloud2biz.com/bizpaas](https://cloud2biz.com/bizpaas) |

## Locations

Our services are offered in the following data center locations:

- **Istanbul Europe-1** — Türkiye
- **Istanbul Europe-2** — Türkiye
- **Ankara** — Türkiye
- **Sofia** — Bulgaria (European Union)

For details of the data center infrastructure, see [Data Center](./kurumsal/veri-merkezi.md).
