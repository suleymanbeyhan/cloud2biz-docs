**Müşteri paneli** ([cloud2biz.com/clientarea](https://cloud2biz.com/clientarea)), Cloud2Biz hesabınızı, hizmetlerinizi ve ödemelerinizi yönettiğiniz yerdir.

## Panelin Bölümleri

Sol menü iki bölümden oluşur:

| Bölüm | Menü | İçerik |
| --- | --- | --- |
| **Yönet** | **Kontrol Paneli** | Hesabınızın genel görünümü |
| | **Hizmetler** | Satın aldığınız tüm hizmetler ve hizmet ayrıntıları |
| **Hesap** | **Hesap Detayları** | Kişisel / kurumsal bilgileriniz ve fatura bilgileriniz |
| | **Yetkililer** | Hesabınıza erişebilecek ek kullanıcılar |
| | **Ödeme** | Ödeme işlemleri ve bakiye |
| | **Güvenlik** | Hesap güvenliği ayarları |

Üst menüde **Arama**, yeni hizmet almak için **Satın Al** butonu, alışveriş sepeti, bildirimler ve hesap bakiyeniz yer alır.

## Hizmet Ayrıntıları

**Hizmetler** bölümünden bir hizmeti seçtiğinizde hizmet sayfası açılır. Örneğin bir FlexoStack hizmetinde şu sekmeler bulunur:

| Sekme | İçerik |
| --- | --- |
| **Giriş Detayları** | Hizmet paneline giriş adresi (URL), kullanıcı adı ve parola |
| **Sunucu Listesi** | Hizmet altındaki sunucular |
| **Kaynaklar** | Hizmete tanımlı kaynaklar |
| **Fatura** | Hizmete ait faturalar |

FlexoStack paneline giriş adımları için [FlexoStack Paneline Giriş](/docs/flexostack-cloud/ilk-adimlar/panele-giris) sayfasına bakın.

## Sık Yapılan İşlemler

| İşlem | Nasıl yapılır? |
| --- | --- |
| Yeni hizmet satın alma | Üst menüden **Satın Al** |
| Hizmet kaynaklarını artırma / azaltma | **Hizmetler** > ilgili hizmet > **Paket yükseltme**. Bkz. [Ödeme ve Faturalar](../odeme/odeme-ve-faturalar.md#paket-değişiklikleri) |
| Fatura görüntüleme ve ödeme | **Ödeme** bölümü veya hizmet sayfasındaki **Fatura** sekmesi |
| Fatura bilgilerini güncelleme | **Hesap Detayları** |
| Destek talebi oluşturma | Bkz. [Destek ve İletişim](../destek/destek-ve-iletisim.md) |
